# Geography in LLM Decision-Making

Research by Hoffmann Muki and Pritika Ramu on country-name effects in ambiguous conflict-event classification.

[Project overview and commands](interpretability/README.md) · [Study design](interpretability/country_effect/part1_behavioral/DESIGN.md) · [Report](interpretability/country_effect/main.tex)

Install dependencies with `python3 -m pip install -r interpretability/requirements.txt`. Run the study commands from `interpretability/`.

Raw ACLED exports in `conflict_data/` support rebuilding the [materials](interpretability/MATERIALS.md). Released datasets and results are under `interpretability/country_effect/part1_behavioral/`.
